# 🎓 Интеллектуальные викторины

Интерактивный веб-сайт с двумя играми-квизами: «Интересные факты о преподавателях» и «Кто хочет стать миллионером». Чистый HTML + Tailwind CSS + vanilla JavaScript, без сборки.

## ✅ Реализованные возможности

### Навигация и экраны
- **Главная страница** — заголовок и две крупные стильные карточки игр с hover-анимацией.
- **Экран выбора смены** — показывается только для Игры 1 («1 смена» / «2 смена»).
- Игра 2 («Миллионер») стартует сразу, без экрана выбора смены.
- Кнопка **«Назад в меню» / «Выйти»** — на каждом игровом экране.

### Игра 1: «Интересные факты о преподавателях»
- Данные 1 и 2 смены встроены из файла `Ответы_преподавателей_по_сменам.xlsx` (25 преподавателей).
- Случайный факт → 4 варианта ответа (1 правильный + 3 случайных из той же смены).
- Зелёная подсветка при верном ответе, красная при ошибке + показ правильного ответа.
- Кнопка «Следующий факт», прогресс-бар, счёт, финишный экран с итогом очков и «Сыграть снова».

### Игра 2: «Кто хочет стать миллионером»
- Фирменный сине-золотой дизайн TV-шоу: панель вопроса, слоты A/B/C/D, денежная лестница (100 → 300 → 500 → 700 → 900 → 1000).
- Выбор одной из 7 категорий вопросов (данные из `кто хочет стать миллионером.xlsx`, встроены в JS).
- Если у вопроса меньше 4 вариантов — автоматически формируются 4 логичных варианта с 1 правильным.
- Выбор ответа: жёлтая пульсация («раздумье») → зелёный (верно) / красный (ошибка, показ правильного).
- Три подсказки (по одному разу за игру, помечаются красным ✕ после использования):
  - **50/50** — убирает 2 неверных ответа;
  - **Помощь зала** — анимированная диаграмма голосов (зал «увереннее» на лёгких вопросах);
  - **Звонок другу** — друг советует вариант с указанием уверенности (прав в ~85% случаев).
- Финишные экраны победы («🏆 ПОБЕДА!») и поражения (с показом правильного ответа и заработанных баллов).

## 📁 Структура проекта

```
index.html        — все экраны (меню, выбор смены, игры, финиши, модалка подсказок)
css/style.css     — стили: экраны, «миллионер» (сине-золотая тема), лестница, подсказки
js/data.js        — встроенные данные: TEACHERS_DATA (2 смены) и MILLIONAIRE_DATA (7 категорий)
js/app.js         — логика: навигация по экранам + механика обеих игр
```

## 🔗 Точки входа

- `/` или `/index.html` — единственная страница; навигация внутри неё через JS-экраны (без перезагрузок).
- Параметры URL не используются.

## 🧩 Модели данных

Хранятся в `js/data.js` (клиентская вставка из xlsx-файлов):

- `TEACHERS_DATA`: `{ "1 смена": [{name, fact}…], "2 смена": [{name, fact}…] }`
- `MILLIONAIRE_DATA`: `{ "<категория>": [{points, question, correct, options[]}] }` — 7 категорий × 6 вопросов
- `MILLIONAIRE_LADDER`: `[100, 300, 500, 700, 900, 1000]`

Серверное хранилище/таблицы не используются — игра полностью клиентская.

## 🚧 Не реализовано / идеи для развития

- Таймер на ответ в «Миллионере» (как в оригинальном шоу).
- Несгораемые суммы на лестнице, звуковое сопровождение (музыка шоу).
- Таблица рекордов (через RESTful Table API), мультиплеер/очный режим.
- Загрузка вопросов из xlsx напрямую в браузере (SheetJS) для обновления базы без правок кода.
